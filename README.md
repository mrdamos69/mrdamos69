I build and maintain AI agents and full-stack applications for service businesses, focusing on customer inquiries, estimates and booking workflows. I work with Python, TypeScript, OpenAI and Anthropic.

Freelance software engineer on Upwork since March 2023. School 21, 2022-2025. Based in Los Angeles.

## Selected work

**[Lead qualification and estimating agent](https://github.com/mrdamos69/ai-lead-estimating-agent)**

A public Python demo using synthetic data: lead qualification, Pydantic validation, OpenAI tool calling and deterministic pricing. Produces drafts for human review, not automatic customer messages.

**[Service request web application](https://github.com/mrdamos69/home-hero-handyman)**

A Next.js and TypeScript application with request handling, attachment validation and email delivery. It demonstrates the intake side of a service workflow; the public repository does not include a connection to the agent above.

These repositories show selected examples, not the full scope of my work. Client projects covered by NDAs are not published here.

## How I work

- Turn client requirements into scoped implementations and maintain the resulting workflows.
- Separate generated content from deterministic business rules and validate data at system boundaries.
- Use AI-assisted coding with scoped tasks, isolated Git worktrees, tests and independent review of changes.
